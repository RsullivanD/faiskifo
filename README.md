# Faiskifo

Prototype simple pour découper les tâches en étapes et lutter contre la procrastination.

Site publié via GitHub Pages : https://faiskifo.avecjoie.ca

## Tester localement
- Ouvrir `index.html` dans un navigateur (site statique).
- Les données sont stockées dans `localStorage`. Utilise l'option Export/Import pour sauvegarder et restaurer les données.

## Fonctionnalités
- Piger une étape, lancer un minuteur, marquer comme terminée.
- Export/import JSON pour sauvegarde locale.
- CNAME pour domaine personnalisé (déjà ajouté).

## Déploiement
- GitHub Pages est activé sur la branche `main` et le dossier racine. Si le certificat HTTPS n'est pas encore disponible, attends quelques minutes puis coche « Enforce HTTPS » dans Settings → Pages.
